
### 1. 事件處理器（Event Handlers）

事件處理器允許我們在使用者與網頁進行互動時（例如點擊按鈕、輸入文字），執行特定的 JavaScript 函式 。

- **點擊事件 (`onClick`)**：當按鈕被點擊時觸發 。
    
    JavaScript
    
    ```ts
    // 建立 onClick 事件處理器
    <button onClick={handleSendMessage}>Send Message</button>
    ```
    
- **輸入改變事件 (`onChange`)**：當 `<input>` 文字方塊的內容改變時觸發 。它可以透過傳入的 `event` 物件取得使用者的輸入內容 ：
    
    - `event.target` 指向觸發事件的 HTML 元素（即文字方塊本身）。
        
    - `event.target.value` 則可抓取目前文字方塊內最新的文字字串 。
        
    
    JavaScript
    
    ```ts
    <input onChange={(event) => { console.log(event.target.value); }} />
    ```
    

### 2. 狀態管理（State）

在 React 中，State（狀態）是指「會隨時間改變，且與網頁 HTML 渲染緊密相連的資料」 。當我們更新 State 時，React 會自動為我們重新渲染並更新網頁畫面，不需要手動操作 DOM 。

- **語法與陣列解構 (Array Destructuring)**：使用 React 提供的 `useState` 鉤子來建立狀態與其對應的更新函式（Updater function） 。
    
    JavaScript
    
    ```ts
    // 語法範例
    const [inputText, setInputText] = React.useState('');
    ```
    
- **雙向綁定與清空輸入框**： 若要讓文字方塊受 State 控制，需加上 `value` 屬性 。當按下送出按鈕後，調用更新函式將狀態設為空字串 `''`，即可同步清空畫面上的輸入框 。
    
    JavaScript
    
    ```ts
    <input 
      value={inputText} 
      onChange={(event) => setInputText(event.target.value)} 
    />
    ```
    

### 3. 狀態提升（Lifting State Up）

當多個組件需要共享或同步同一組資料時（例如：`<ChatInput>` 需要改變聊天訊息陣列，而訊息列表組件需要顯示它），必須採用**狀態提升**技術 。

- **定義**：將 State 從各自的子組件中移出，共同「提升」到它們最近的父組件（通常是 `<App />` 組件）中進行統一管理 。
    
- 父組件再透過 **Props** 將資料（如 `chatMessages` 陣列）或操作狀態的函式傳遞給子組件。
    

### 4. 聊天機器人專案功能（Chatbot Project Features）

在聊天機器人實作中，結合了陣列資料處理與模擬 AI 回覆的邏輯 ：

- **動態渲染列表 (`map` 與 `key`)**：使用 JavaScript 的 `map()` 陣列方法來遍歷儲存訊息的陣列物件，動態產生對應的 HTML 結構，且每個元素都必須賦予唯一的 `key` 屬性以優化渲染效能 。
    
- **模擬 Chatbot 自動回覆**： 當使用者點擊 `send` 建立新訊息時，會先將使用者的訊息加入陣列，隨後再將機器人的預設訊息一併更新至狀態中 。
    
    **核心實作邏輯程式碼範例：**
    
    JavaScript
    
    ```ts
    function handleSendMessage() {
      // 1. 建立包含使用者新訊息的新陣列
      const newChatMessages = [
        ...chatMessages,
        { message: inputText, sender: 'user' }
      ];
    
      // 2. 判定使用者輸入以給予相應的機器人回覆 (模擬基礎功能如：flip a coin / date)
      let botResponse = 'Hello! How can I help you?';
      if (inputText.includes('date')) {
        botResponse = `Today's date is ${new Date().toLocaleDateString()}`;
      } else if (inputText.includes('coin')) {
        botResponse = Math.random() < 0.5 ? 'Sure, you got heads!' : 'Sure, you got tails!';
      }
    
      // 3. 同時更新使用者與機器人的對話訊息至狀態中
      setChatMessages([
        ...newChatMessages,
        { message: botResponse, sender: 'chatbot' }
      ]);
    
      // 4. 清空輸入框
      setInputText('');
    }
    
    ```
