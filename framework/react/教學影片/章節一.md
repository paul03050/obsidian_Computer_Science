
### 完整的 `react-basics.html` 檔案程式碼

HTML

```html
<!DOCTYPE html>
<html>
  <head>
    <title>React Basics</title>
  </head>
  <body>
    <div class="js-container"></div>

    <script src="https://unpkg.com/react@19/umd/react.development.js"></script>
    <script src="https://unpkg.com/react-dom@19/umd/react-dom.development.js"></script>

    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>

    <script type="text/babel">
      // 取得 HTML 中的容器節點
      const container = document.querySelector('.js-container');
      
      // 以該容器建立 React 的根節點（Root）
      const root = ReactDOM.createRoot(container);

      // 使用 JSX 語法建立包含多個元素的變數（最佳實踐：使用小括號包覆並縮排）
      const mainElement = (
        <div>
          <button>hello</button>
          <p>paragraph of text {2 + 2}</p>
        </div>
      );

      // 將 JSX 元素渲染（顯示）到網頁容器中
      root.render(mainElement);
    </script>
  </body>
</html>
```

### 💡 程式碼重點演進說明（教材脈絡）：

1. **基本設置**：最初課程中僅使用 `root.render('welcome to super simple dev react course')` 來顯示單純的字串 。
    
2. **單一元素變數**：隨後引進 JSX，可直接將 HTML 標籤指派給變數（如 `const button = <button>hello</button>;`），並將變數傳入 `root.render(button)` 顯示單個按鈕 。
    
3. **多元素渲染限制與解決**：React 一次只能回傳或渲染**單一根元素**，因此需要多個標籤時（例如同時要有按鈕與段落），必須使用一個 `<div>` 將它們包起來 。
    
4. **格式與大括號運算**：依照最佳實踐（Best Practice），多行 HTML 建議用**小括號 `()`** 包裹，且在標籤內部使用**大括號 `{}`** 可以直接嵌入 JavaScript 的運算（例如 `{2 + 2}` 會在畫面上渲染出 `4`） 。
