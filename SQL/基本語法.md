SQL（結構化查詢語言）常用語法主要分為==資料查詢（DML）、資料操作（DML）與資料定義（DDL）==三大核心範疇。 

以下為您整理實務上最常使用的 SQL 語法與範例：

## 一、 資料查詢（SELECT）— 最常用的核心語法

用於從資料庫中撈取與篩選資料。 

- 基礎查詢：
    
    ```sql
    SELECT 欄位1, 欄位2 FROM 資料表;
    SELECT * FROM 資料表; -- 查詢所有欄位
    ```
    
- 條件篩選（WHERE）：
    
    ```sql
    SELECT * FROM employees WHERE salary >= 50000;
    ```
    
- 多重條件（AND / OR / NOT）：
    
    ```sql
    SELECT * FROM employees WHERE dept = 'IT' AND status = 'Active';
    ```
    
- 模糊查詢（LIKE）（`%` 代表任意多個字元）：
    
    ```sql
    SELECT * FROM employees WHERE name LIKE '張%'; -- 搜尋姓張的人
    ```
    
- 範圍與集合（BETWEEN / IN）：
    
    ```sql
    SELECT * FROM employees WHERE age BETWEEN 25 AND 35;
    SELECT * FROM employees WHERE dept IN ('IT', 'HR', 'Sales');
    ```
    
- 結果排序（ORDER BY）（`ASC` 升冪，`DESC` 降冪）：
    
    ```sql
    SELECT * FROM employees ORDER BY salary DESC;
    ```

## 二、 資料聚合與分組（Aggregation & Grouping）

用於數據統計與分析。 

- 常用聚合函數：`COUNT()` 計算筆數、`SUM()` 加總、`AVG()` 平均、`MAX()` 最大值、`MIN()` 最小值。
- 分組統計（GROUP BY）與分組篩選（HAVING）：
    
    ```sql
    -- 計算各部門的平均薪資，且只顯示平均薪資大於 60000 的部門
    SELECT dept, AVG(salary) 
    FROM employees 
    GROUP BY dept 
    HAVING AVG(salary) > 60000;
    ```
    

---

## 三、 多表連接（JOIN）

用於將兩張以上有關聯的資料表結合查詢。 [3, 6]

- 內連接（INNER JOIN）：僅取出兩張表皆符合條件的資料。
- 左外連接（LEFT JOIN）：保留左表所有資料，右表無匹配則顯示 NULL。
    
    ```sql
    SELECT e.name, d.dept_name 
    FROM employees e
    LEFT JOIN departments d ON e.dept_id = d.id;
    ```
    

---

## 四、 資料操作（INSERT, UPDATE, DELETE）

用於對資料表內部的數據進行新增、修改與刪除。 

- 新增資料（INSERT INTO）：
    
    ```sql
    INSERT INTO employees (name, dept, salary) VALUES ('王小明', 'Marketing', 45000);
    ```
    
- 更新資料（UPDATE）（⚠️務必加 WHERE 條件，否則會更新整張表）：
    
    ```sql
    UPDATE employees SET salary = 52000 WHERE name = '王小明';
    ```
    
- 刪除資料（DELETE）（⚠️務必加 WHERE 條件，否則會清空資料）：
    
    ```sql
    DELETE FROM employees WHERE status = 'Resigned';
    ```
    


---

## 五、 資料定義（DDL）

用於建立或修改資料庫結構（如資料表）。 

- 建立資料表（CREATE TABLE）：
    
    ```sql
    CREATE TABLE employees (
        id INT PRIMARY KEY AUTO_INCREMENT,
        name VARCHAR(50) NOT NULL,
        salary INT,
        join_date DATE
    );
    ```
    
- 修改資料表結構（ALTER TABLE）：
    
    ```sql
    ALTER TABLE employees ADD phone VARCHAR(20); -- 新增欄位
    ```
    
- 刪除整個資料表（DROP TABLE）：
    
    ```sql
    DROP TABLE employees;
    ```
