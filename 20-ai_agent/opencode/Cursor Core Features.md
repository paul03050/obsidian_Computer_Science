根據您提供的「普通人也可以看的 AI 編程指南」檔案內容，以下為您整理 Cursor 的核心功能、使用技巧、免費（白嫖）方法以及繞過設備檢測的完整攻略：

### 一、 Cursor 核心功能

1. **Cursor Tab（代碼自動補全與預測）**
    
    - **功能**：不僅能自動補全代碼，最受好評的是**光標預測（Tab-Tab-Tab）** 。Cursor 能預測您下一個要編輯或修改的位置，您只需一直按 `Tab` 鍵，光標就會自動跳到該處並完成修改，極大地節省了處理繁雜、重複代碼的時間 。
        
2. **Chat 模式與 Composer 模式**
    
    - **Chat 模式（`Ctrl/Cmd + L`）**：類似 ChatGPT 的問答聊天框，主要用於分析需求、詢問方案與理解代碼，此模式具備上下文記錄 。
        
    - **Composer 模式（`Ctrl/Cmd + I`）**：不僅能回答，還能**直接幫您批量修改或創建項目中的現有代碼**，無需離開工作流 。
        
    - **模型推薦**：生成代碼建議在 Composer 模式使用 **Claude 3.5 Sonnet**；分析需求與綜合問答建議在 Chat 模式使用 **GPT-4o** 。
        
3. **Composer 的兩種運行模式**
    
    - **Normal 模式**：可以檢索代碼庫和文檔，正常創建與寫入文件，速度較快，適合處理簡單功能 。
        
    - **Agent 模式**：除了創建模擬文件外，還能**自動提取相關上下文、運行終端命令、執行文件操作**，適合處理複雜功能（目前僅支持 Claude 模型，速度較慢） 。
        

### 二、 高效使用技巧（`@` 符號的妙用）

在 Chat 或 Composer 聊天框中輸入 `@` 符號，可以喚醒功能菜單來精準限制 AI 的理解範圍，避免 AI 亂改代碼 ：

- **`@Files` / `@Folders`**：引用特定的文件或文件夾作上下文（亦可直接拖拽文件夾進聊天框） 。
    
- **`@Docs`**：引入自定義或官方文檔。若添加 URL 時在末尾加上斜槓（例如 `URL/`），Cursor 除了索引該頁面外，還會**自動抓取其下所有的子頁面和子目錄** 。
    
- **`@Web`**：讓 Cursor 具備 AI 搜尋引擎的能力，即時查詢網絡上最新的技術或報錯解決方案 。
    
- **`@Git`**：可選中某一次或多次的歷史提交（Commit），讓 AI 幫忙審查代碼或對比多次提交之間的差異以查找 Bug 。
    
- **`@Notepad`**：記事本功能。由於 Chat 和 Composer 的上下文默認是不互通的，您可以將開發思路或 AI 的對話歷史記錄在 Notepad 中，再通過 `@Notepad` 讓兩邊都能讀取，充當**上下文互通的橋樑** 。
    
- **`@Codebase`**：Cursor 會掃描整個項目，將本地代碼分割成語言數據進行分析與推理，給出最匹配的解答 。
    
    - _小提示_：建議在根目錄配置 `.cursorignore` 文件，忽略不需索引的目錄（如依賴庫），以縮小範圍，讓代碼生成更準確 。
        

### 三、 實戰開發思路（預防 AI 亂改代碼）

如果您想用 Cursor 獨立開發產品或修改複雜需求，請遵循以下步驟 ：

1. **先問後做（Chat -> Composer）**：遇到複雜需求時，**絕對不要一上來就讓 Composer 反復生成** 。應該先在 **Chat 模式**中把技術方案、目錄結構、運行方式問明白 。
    
2. **需求拆解**：將大需求拆解成一個個細粒度的功能（Features），用 `Notepad` 單獨記錄 。
    
3. **安全審查與檢測**：當 Composer 幫您修改多個文件時，可以點擊 **`Save All`（保存所有）**，先直接運行項目查看實際效果 。若符合預期則點擊 `Accept All`，不符合則點擊 `Reject All` 取消修改，並重新調整提示詞 。
    

### 四、 如何免費使用 Cursor（白嫖攻略）

由於 Cursor 是採用郵箱註冊機制，每個新賬號擁有 14 天的免費專業版（Pro）試用期 。因此白嫖的策略是**每 14 天（或當免費 API 額度用完時）更換新郵箱重新註冊** 。

- **獲取無線郵箱的方法**：
    
    1. 使用**臨時郵箱平台**：自動分配臨時賬號，只需用來接收註冊驗證碼即可 。
        
    2. 使用**無線郵箱（子母郵箱）設定**：利用主流郵箱的別名機制，在同一個主郵箱後綴前隨便增加字符生成子郵箱註冊，但所有的驗證信依然會寄到您的主郵箱中 。
        

### 五、 如何繞過 Cursor 設備指紋檢測

**背景問題**：當您在同一台電腦上頻繁更換免費賬號登錄時，Cursor 的最新更新會限制該設備的使用，導致無法發送指令（提示設備檢測異常） 。

**解決原理與方法**：

- **原理**：通過修改 Cursor 配置文件中與用戶設備指紋（Device ID / Machine ID）相關的參數，讓服務器誤以為是一台全新的設備在登錄 。
    
- **實操腳本**：
    
    1. 您可以使用 Node.js 寫一個自動替換指紋參數的腳本，或將其轉換成終端可直接執行的腳本（Mac/Linux 使用 `.sh` 檔案，Windows 使用 `.ps1` 檔案） 。
        
    2. 為了更方便使用，也可以利用工具將該腳本封裝成各個系統對應的**可執行文件（如 `.exe`）** 。
        
    3. **運行流程**：雙擊運行該可執行文件。運行過程中，腳本如果檢測到 Cursor 正在運行，會提示並關閉 Cursor（輸入 `y` 確定關閉） 。
        
    4. 當終端顯示修改成功後，直接關閉終端，此時您的設備指紋就已刷新，可以繼續登錄新賬號白嫖 。
        
    5. _注意_：此工具不要刪除，未來若再次遇到設備限制，重新雙擊執行一次即可 。
