
## ## 1. 基礎啟動與模式切換

在終端機進入專案目錄後，可使用以下命令與快捷鍵：

- **啟動 TUI（終端用戶界面）：** ```bash
    
    open Code
    
    ```
    這是最核心的使用方式，所有的對話、代碼修改、文件操作皆在此完成 [cite: 4, 6]。
    ```
    
- **主智能體切換（按 `Tab` 鍵切換）：**
    
    - **Build 模式 (`B`)：** 預設模式。擁有完整的文件讀寫與命令執行權限，用於日常編碼、修改與重構 。
        
    - **Plan 模式 (`P`)：** 只讀規劃模式。不可修改文件或執行命令，用於在動手前分析代碼結構並輸出詳細執行方案，避免 AI 改錯地方 。
        
- **呼叫子智能體（輸入 `@`）：**
    
    - `@Explorer`：只讀的代碼探索器，適合在大型專案快速定位功能實際位置 。
        
    - `@general`：通用子智能體，處理獨立任務，不污染主對話上下文 。
        
- **模糊搜尋專案文件（輸入 `#`）：**
    
    - 輸入 `#` 後接文件名，選中後會自動將文件內容注入對話中 。
        

## ## 2. TUI 常用內置斜線命令 (`/`)

在 TUI 介面中，可使用斜線開頭的命令進行環境與對話管理（或按 `Ctrl + P` 呼叫功能面板）：

| **命令**   | **功能說明**                                                                |
| -------- | ----------------------------------------------------------------------- |
| `/cnect` | **連接模型供應商**。整合了超過 75 家大模型（含雲端大廠與本地 Ollama），亦內置官方免費模型，輸入後填入 API Key 即可 。 |
| `/modle` | **查看與切換模型**。可在同一個會話中隨時切換已連接的模型，無需重啟對話 。                                 |
| `/sence` | **歷史會話管理**。瀏覽、搜索與恢復過去的對話記錄 。                                            |
| `/share` | **生成分享連結**。將完整對話生成連結並複製到剪貼簿，方便團隊協作 。                                    |
| `/undo`  | **撤銷修改**。AI 修改文件前會自動建立 Git 快照，不滿意可連續撤銷回推 。                              |
| `/rad`   | **恢復撤銷**（Redo）。                                                         |
| `/think` | **切換推理過程顯示**。開啟後可看到 AI 的思考分析步驟，方便及時糾正方向 。                               |
| `/init`  | **專案初始化**。自動掃描結構並在根目錄生成 `agent.md`（專案說明書），讓 AI 回答更貼合技術棧與規範 。            |

## ## 3. 終端命令模式與快捷操作

- **直接執行終端命令（輸入 `!`）：** 在 TUI 輸入框開頭加上驚嘆號，不需退出 OpenCode 即可執行指令 。例如：
    
    - `!ls`：瀏覽當前目錄 。
        
    - `!npm test`：運行測試 。
        
    - `!git status`：查看倉庫狀態 。
        
- **圖片輸入：** 直接將圖片**拖進終端**或**直接貼上剪貼簿中的圖片**，OpenCode 會自動讀取圖片內容加入對話（非常適合前端 UI 問題溝通）。
    

## ## 4. CLI 獨立命令（非交互模式）

無需進入 TUI 界面，直接在終端機操控 OpenCode，適合 CI/CD 或腳本自動化 ：

- **單次任務執行：**
    
    Bash
    
    ```
    opencode run "你的提示詞"
    ```
    
    常用參數：`--model`（指定模型）、`--agent`（指定智能體）、`--File`（附帶文件）、`-S`（自動分享結果）。
    
- **啟動 Web 模式：**
    
    Bash
    
    ```
    opencode wb
    ```
    
    自動打開瀏覽器網頁介面，界面與 TUI 一致，可透過區域網路讓其他設備連線使用 。
    
- **遠端連接服務：**
    
    Bash
    
    ```
    opencode attach <服務器地址>
    ```
    
    本地端 TUI 直接連線到遠端伺服器上運行的 `opencode serve` 後端 。
    
- **帳單與費用統計：**
    
    Bash
    
    ```
    opencode state
    ```
    
    按時間、模型或專案拆分，一目了然看清 Token 使用量與花費 。
    
- **模型管理與刷新：**
    
    - `opencode models <供應商>`：列出可用模型 。
        
    - `opencode models wbs`：查看每種模型的定價信息 。
        
    - `opencode models rifrice`：強制刷新模型緩存 。
        
- **會話導出與導入：**
    
    - `opencode session list`：查看所有會話 。
        
    - `opencode session delete <ID>`：刪除指定會話 。
        
    - `opencode session export`：導出為 JSON 。
        
    - `opencode session impin`：從本地或分享連結導入 。
        
- **系統升級與徹底卸載：**
    
    - `opencode upgrade`：升級至最新版本 。
        
    - `opencode any stop`：徹底卸載並清理所有文件 。
        

## ## 5. 高級自定義與進階語法

OpenCode 的核心配置由 `opencode.json`（或支援註解的 `opencode.jsonc`）文件控制 。
### 5.1 自定義命令 (`command`)

可在配置中將常用的長提示詞封裝成快捷斜線命令（例如：`/fix test`）：

- **參數代入：** 使用 `$arguments` 代表命令後的所有參數，或用 `$1`, `$2` 代表特定位置參數 。
    
- **命令輸出注入提示詞：** 在模板中使用 `\`! <終端命令>`` 語法，系統會自動執行該終端命令，並將輸出的結果直接注入作為 AI 的提示詞 。
    

### 5.2 自定義智能體 (`agent`)

- **命令創建：** `opencode agent create`，跟隨引導設定名稱、描述、權限、模型後自動生成設定 。
    
- **手動創建：** 在對應目錄創建 `<智能體名稱>.md`，頂部寫入配置，正文寫入 System Prompt（系統提示詞）。
    

### 5.3 技能模組 (`skills`)

- 存放在 `skills/skills.md` 中，與固定模板的自定義命令不同，`skills` 是**上下文感知**的指令集 。
    
- 當對話觸發特定場景（如詢問部署問題），AI 會自動加載對應的 skill 知識來引導操作 。
    

### 5.4 外部生態與工具

- **MCP (Model Context Protocol)：** 支援 `local` 與 `remote` 配置，讓 AI 直接調用外部工具，如結合 `CEXT 7` 搜尋即時文檔、連結 `Sentry` 自動讀取線上報錯日誌、使用 `grip.app` 搜尋 GitHub 公開代碼等 。
    
- **自定義工具 (Custom Tools)：** 允許使用 TypeScript/JavaScript 撰寫函數，讓 AI 在對話中直接調用（函數內部可再透過子進程調用 Python 或 Go）。
    

> 💡 **小貼士**：OpenCode 是一款完全免費且開源的工具。日常配置建議從最精簡的 `model` 和 `auto update` 開始，再根據項目需要逐步疊加進階功能 。
