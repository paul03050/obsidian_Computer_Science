### …or create a new repository on the command line
``` bash
echo "# obsidian_erp" >> README.md
git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/paul03050/obsidian_erp.git
git push -u origin main
```
### …or push an existing repository from the command line
```bash
git remote add origin https://github.com/paul03050/obsidian_erp.git
git branch -M main
git push -u origin main
```
