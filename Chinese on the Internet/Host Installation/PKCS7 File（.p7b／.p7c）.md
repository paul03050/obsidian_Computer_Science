## 重點摘要

這份文件說明網路中文販售 SSL 憑證後，客戶下載的壓縮檔內各檔案的功能與使用時機，並提供客服判斷與回應客戶的實務指引。

### 一、SSL 憑證信任鏈三層
- **網站憑證（Server Certificate）**：證明網域身分，如 `www.example.com`，好比網站的身分證。
- **中繼憑證（Intermediate Certificate）**：建立網站憑證與上層 CA 的信任關係，實際可能不只一張。
- **根憑證（Root Certificate）**：信任鏈最上層，通常已內建於作業系統或瀏覽器，伺服器不一定需要傳送。

### 二、壓縮檔內各資料夾／檔案
- **CER - CRT Files**：放 `.crt` 憑證檔，含網站憑證、根憑證、交叉簽署憑證、中繼憑證，以及 `My_CA_Bundle.ca-bundle`。檔名為特定時期 Sectigo 鏈配置，不能單憑檔名認定必要性。
- **My_CA_Bundle.ca-bundle**：把多張 CA 憑證依信任鏈順序整合成一個檔案。若只裝網站憑證而缺中繼憑證，可能導致鏈不完整、檢測工具顯示 Chain 不完整、部分裝置出現信任錯誤。但各伺服器（Apache／Nginx／Plesk／IIS）安裝方式不同。
- **PKCS7 File（.p7b／.p7c）**：憑證封裝格式，可含網站憑證與中繼憑證，**通常不含私密金鑰**。常用於 IIS、Windows 憑證管理、Java Tomcat、Azure。
- **Plain Text Files**：憑證的純文字版本，與 `.crt` 差在呈現方式與副檔名，密碼學功能相同。另存 `.crt` 時須保留完整內容與 BEGIN／END 標記。
- **!PRIVATE KEY INFO!.txt**：提醒憑證檔**不含私密金鑰**。私鑰由客戶產生 CSR 時自行保留；遺失私鑰無法靠重新下載 CRT 解決，須重新產生金鑰與 CSR，並視情況申請 Reissue。
- **Choosing the Right Files to Install.txt**：相當於安裝說明書，說明各資料夾用途與適用伺服器格式。

### 三、客服實務判斷表
| 客戶問題            | 先確認什麼                |
| --------------- | -------------------- |
| 不知道裝哪個 CRT      | 伺服器種類                |
| 說缺少 CA Bundle   | 伺服器是否需要完整鏈檔案         |
| IIS 要裝哪個        | 是否用 PKCS#7 或 PFX 等格式 |
| Plesk 要裝哪個      | 網站憑證、私鑰、CA 憑證欄位      |
| 找不到 Private Key | 當初 CSR 在哪台主機產生       |
| 安裝後仍錯誤          | 憑證鏈、網域、有效期限、伺服器設定    |

### 四、排查順序（客戶說「裝了 CRT 還是 SSL 錯誤」）
1. 確認網站憑證：網域是否正確、是否過期
2. 確認 Private Key：是否與憑證公鑰配對
3. 確認中繼憑證：是否安裝正確
4. 確認 CA Bundle：是否需匯入完整信任鏈
5. 用 SSL Checker 檢測鏈、回傳憑證與有效期限

### 五、核心區別（最該優先掌握）
1. **CRT vs CA Bundle**：前者可能是一張憑證，後者通常整合多張 CA 憑證。
2. **CRT vs Private Key**：憑證不能取代私密金鑰。
3. **PKCS#7 vs PFX**：兩者都能封裝憑證，但 PFX／P12 可含私密金鑰，PKCS#7 通常不含。

### 六、客戶說「上游 CA 給的 CRT 和客服寄的不一樣」的可能原因
1. **檔案組成不同**：CA 後台讓客戶個別下載單一網站憑證，網路中文寄的是含完整信任鏈的整套壓縮檔。
2. **比對到不同資料夾的同名檔案**：Plain Text Files 是 `.crt` 的純文字版本，內容主體相同但呈現方式不同。
3. **非 Sectigo 品牌命名不同**：其他 CA 未必附中繼與根憑證，資料夾結構本來就不同，不能直接與 Sectigo 範例比對。
4. **少了私密金鑰是正常的**：私鑰由客戶產生 CSR 時保留，CA 與網路中文都不會提供。

### 七、建議客服話術方向
向客戶說明：我們寄的是整理好的完整壓縮檔（含網站憑證、中繼憑證、根憑證與 `My_CA_Bundle.ca-bundle`），CA 後台通常只能個別下載單一網站憑證；安裝時通常需要完整信任鏈。可請客戶對照 `Choosing the Right Files to Install.txt`，並告知伺服器類型（Apache／Nginx／IIS）以便協助確認該放哪些檔案。
