可以，但要先確認客戶所說的「域名鎖」是哪一種。**如果客戶正在辦理域名轉出（Transfer Out），通常需要解除的是「轉移鎖（Registrar Lock／Transfer Lock）」**，讓新註冊商可以接收該域名的轉入申請。

不過，客服不能只聽到「解鎖」就直接操作，還要確認域名狀態及公司作業權限。

## **1. 域名轉出為什麼需要解鎖？**

假設：

- 目前註冊商：網路中文
    
- 新註冊商：B 公司
    
- 客戶想把 `example.com` 從網路中文轉到 B 公司
    

一般流程：

**網路中文**

原註冊商

解除 Transfer Lock，取得 AuthInfo / EPP Code

**B 公司**

新註冊商，提交轉入申請

如果域名仍處於轉移鎖定狀態，新註冊商可能無法順利發起轉入。

## **2. 客服要怎麼確認？**

可以先查詢域名的 Domain Status。

以常見的 `.com` 等 gTLD 為例：

|Domain Status|意義|處理方向|
|---|---|---|
|`clientTransferProhibited`|註冊商端設定轉移鎖|確認是否可解除|
|`serverTransferProhibited`|Registry 端限制轉移|需確認限制原因|
|`pendingTransfer`|已進入轉移流程|不要直接當成一般解鎖案件|
|`ok`|沒有特殊狀態限制|仍需確認其他轉出條件|

特別注意：`clientTransferProhibited` 和 `serverTransferProhibited` 不一樣，前者通常是註冊商端設定，後者則是 Registry 端限制。

## **3. 客服實際上應該怎麼處理？**

建議依照以下順序：

1. **確認網域名稱**：客戶要轉出的完整域名是什麼？
    
2. **確認網域後綴**：例如 `.com`、`.net`、`.tw`，不同 Registry 的規則可能不同。
    
3. **查詢 Domain Status**：確認是否有 `clientTransferProhibited`。
    
4. **確認客戶身分及授權**：是否為網域註冊人或經授權的聯絡人。
    
5. **依照公司 SOP 解除鎖定**：確認是否有資格解除，以及是否需要申請文件。
    
6. **確認 AuthInfo Code**：客戶是否也需要取得轉移碼。
    

另外要留意兩種不能單純靠解除一般域名鎖就解決的情況：

- 新註冊後 60 天內。
    
- 最近一次轉移後 60 天內。
    

部分 gTLD 還有註冊人資料變更後的 60 天轉移限制。

## **5. 如果客戶已經在轉出中呢？**

這裡有一個重要區別：

|客戶目前狀態|客服處理方向|
|---|---|
|尚未向新註冊商提出轉入|確認並解除 Transfer Lock|
|新註冊商表示被鎖定，無法申請轉入|查詢 Domain Status，確認鎖定原因|
|已經顯示 `pendingTransfer`|代表轉移程序已進行中，先確認目前轉移狀態，不要直接重複操作|
|顯示 `serverTransferProhibited`|確認 Registry 端限制原因，必要時向技術或上游確認|

ICANN 對一般 gTLD 的規定也要求註冊商提供合理的解鎖方式；若沒有自助解鎖功能，符合條件的申請通常須在收到要求後五個日曆日內處理。這是 ICANN 規範，不能直接套用到所有 `.tw` 域名。

```

```


## **3. 有哪些情況不能直接解鎖？**

要留意：

- 如果是 `serverTransferProhibited`，不是一般註冊商端解鎖就能處理。
    
- 如果網域剛註冊未滿 60 天，可能有轉出限制。
    
- 如果網域剛完成一次註冊商轉移未滿 60 天，也可能無法再次轉出。
    
- 如果有註冊人資料變更後的 60 天轉移鎖，也需要另外確認。

網路中文目前是由客服直接在後台解除 `clientTransferProhibited`，還是需要填寫解鎖申請、轉交技術部門？

那就表示網路中文目前的解鎖流程不是客戶自行操作，而是需要由內部人員人工處理。

這種情況下，你身為客服，應該把案件分成「客戶提出需求 → 客服確認 → 內部人工解鎖 → 確認結果」四個階段。

## **1. 人工作業流程**

1. **接收客戶需求**
    
    客戶表示要將域名轉出，並要求解除 `clientTransferProhibited`。
    
2. **確認域名資料**
    
    - 完整域名
        
    - 客戶是否為註冊人或授權聯絡人
        
    - 是否符合轉出條件
        
    - 是否有其他轉出限制
        
    
3. **提交內部人工解鎖**
    
    依網路中文內部 SOP，將域名及客戶需求提供給有權限的同事處理。
    
4. **確認解鎖結果**
    
    再次查詢 Domain Status，確認 `clientTransferProhibited` 已解除。
    
5. **通知客戶**
    
    告知解鎖完成，並依流程提供 AuthInfo Code 或說明後續取得方式。
    

## **2. 你可以怎麼向內部同事提出？**

您好，客戶欲將網域轉出，目前查詢 Domain Status 顯示為 `clientTransferProhibited`，客戶希望解除域名轉移鎖，以便辦理後續轉出。

再麻煩協助確認是否可以進行人工解鎖，謝謝。

## **3. 客服要特別注意的三件事**

|項目|注意事項|
|---|---|
|解鎖|解除的是註冊商端轉移鎖|
|AuthInfo|解鎖與取得轉移碼是兩件事情|
|轉出完成|解鎖不代表域名已經轉出成功|

另外，人工解鎖時，建議確認內部是否需要客戶填寫申請書、提供身分證明或由註冊人透過指定信箱提出申請。這些屬於公司實際作業規範，不能單憑 `clientTransferProhibited` 就判斷。

**我想再釐清一個關鍵：你們所說的人工解鎖，是客服收到客戶來信後，轉給內部同事操作後台；還是客服自己也能進入後台，但必須人工逐筆解除？**

這兩種模式的客服處理方式會不太一樣。
