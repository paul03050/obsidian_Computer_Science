`services.msc` ==是 Windows 電腦內建的**系統管理工具**==。它的主要功能是查看和控制 Windows 在背景運行的各種程式（稱為「服務」）。你可以想像它是電腦的「幕後工作總管」，負責開啟、關閉或調整各項自動執行的系統功能。 


為什麼要使用它？

- **關閉不需要的功能**：透過停用不常用的服務（如遠端登錄），可以釋放電腦記憶體、提升速度。
- **解決系統錯誤**：當藍牙、印表機或網路無法正常運作時，可以在此將相關的服務重新啟動。

如何開啟它？

1. 按下鍵盤上的 **Win + R** 鍵。
2. 在跳出的「執行」視窗中輸入 `services.msc`。
3. 按下 Enter 即可打開服務管理員清單。

在 Windows 中，您可以使用 **`services.msc`（服務控制台）**來管理 **Windows Search（WSearch）** 服務。這項服務主要負責檔案、電子郵件和其它內容的內容編索引、屬性快取及搜尋結果。


關閉 Windows 系統通知只需幾個簡單步驟。請==按下 **開始 > 設定 > 系統 > 通知**==。在這裡，您可以關閉最上方的通知總開關，或向下滾動清單，關閉特定應用程式的打擾。若要更深入設定，請展開通知選項，取消勾選提示和建議等項目。
