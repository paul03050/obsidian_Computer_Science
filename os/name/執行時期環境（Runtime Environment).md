**執行時期環境（Runtime Environment，簡稱 RTE）**是指程式在執行時所需要的所有軟體與硬體基礎設施。它就像是一個中介層，負責在你的應用程式程式碼與作業系統之間進行溝通。

核心組成要素

每個執行時期環境都包含程式運作所需的關鍵工具：

- **引擎 / 直譯器**：將程式碼轉換成電腦 CPU 看得懂的低階機器指令。
- **記憶體管理**：分配暫存空間（如**堆疊與堆積**），並透過**垃圾回收（GC）**清理不再使用的資料。
- **標準函式庫**：提供內建的常用功能，例如檔案讀寫、文字處理或網路連線。
- **環境變數**：提供外部設定參數，讓程式能動態調整執行行為。


常見範例

不同的程式語言都依賴各自的執行環境來運作：

- **網頁瀏覽器 / Node.js (JavaScript)**：JavaScript 無法直接在電腦上執行。瀏覽器提供了一個包含網頁渲染引擎的執行環境；而 Node.js 則提供了後端執行環境，讓相同的語言可以讀取伺服器硬碟和資料庫。
- **Java 執行時期環境 (JRE)**：包含 [Java 虛擬機 (JVM)](https://zh.wikipedia.org/wiki/Java%E8%99%9A%E6%8B%9F%E6%9C%BA) 與核心函式庫。它確保在 Mac 上編譯的 Java 程式，不需修改就能直接在 Windows 電腦上執行。
- **通用語言執行平台 (CLR)**：微軟 [.NET Framework](https://en.wikipedia.org/wiki/.NET_Framework) 應用程式的核心執行引擎。

執行時期 (Runtime) vs 編譯時期 (Compile Time)

這兩個詞代表軟體生命週期的不同階段：

1. **編譯時期**：工程師撰寫原始碼，並透過編譯器將其轉換成可執行檔（藍圖）的過程。
2. **執行時期**：使用者實際啟動該檔案，執行環境開始配記憶體、啟動 CPU 進行運算的過程。
