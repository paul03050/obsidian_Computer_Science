####  RAM

Chrome 一開機就在後台執行，通常是==因為瀏覽器設定了「允許背景執行」或「開機自動啟動」==。這會占用電腦記憶體。 
1. 關閉 Chrome 背景模式

- 打開 Chrome。
- 點擊右上角「三個點」圖示 ➔ 選擇「**設定**」。
- 點擊左側的「**系統**」。
- 關閉「**關閉 Google Chrome 後繼續執行背景應用程式**」功能。

Brave 瀏覽器佔用過多記憶體 (RAM) 時，可以==透過內建任務管理器關閉肥大分頁、在系統設定中開啟記憶體節省模式，以及刪除少用的擴充功能來快速解決==。

以下是整理好的具體解決步驟：

1. 找出最吃記憶體的兇手

Brave 有內建的任務管理器，能看出到底是哪個分頁或擴充功能吃掉最多記憶體。

- 在鍵盤按下 ==`Shift` + `Esc`== (Mac 請使用對應的捷徑或前往選單)。
- 點擊佔用最高 MB 數的項目，再點下方的 **結束處理程序 (End Process)** 強制關閉。

2. 開啟記憶體節省模式 (Memory Saver)

這個功能會讓閒置的分頁進入睡眠狀態，釋放大量記憶體空間。

- 前往 Brave 的 **設定 (Settings)**。
- 點擊左側的 **系統 (System)**。
- 將 ==**記憶體節省程式 (Memory Saver)** 打開。==

3. 刪除不必要的擴充功能

裝太多擴充功能 (Extension) 會導致記憶體暴增。

- 在網址列輸入 `brave://extensions/` 並前往。
- 檢查是否有重複或沒在用的外掛，直接將它們 **移除 (Remove)**。

4. 關閉背景執行

Brave 預設在關閉瀏覽器後，仍會在背景繼續跑程序。

- 前往 **設定** > **系統**。
- 關閉 **Brave ==關閉時繼續執行背景應用程式== (Continue running background apps when Brave is closed)**。
