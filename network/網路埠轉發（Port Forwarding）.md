
## 🛑 核心概念：什麼是埠轉發？

在預設情況下，網際網路上的外部電腦是無法直接連線到你家私有網路（LAN）中的特定電腦或服務的，因為路由器會把這些未知的外部請求擋下來 。

**埠轉發（Port Forwarding）** 的作用，就是告訴路由器：「**當看到來自網際網路的特定『埠號（Port）』請求時，請把它自動轉發到我內部網路的某一台特定電腦上。**」 這能讓你人在外面，也能存取家裡的電腦、架設網站或遊玩連線遊戲 。

### 📞 經典比喻：公司總機與分機

如果用日常外交來比喻，網路元件與電話系統的對應關係如下 ：

|**網路元件**|**電話系統對應**|**角色與功能说明**|
|---|---|---|
|**IP 地址**|**公司總機號碼**|負責把請求從外面送到公司（路由器），達成目的後功成身退 。|
|**埠號 (Port)**|**分機號碼**|用來決定這個請求具體要找哪一個部門（應用程式/服務） 。|
|**路由器**|**電子總機轉接員**|負責看分機號碼（埠號），並把電話轉接過去 。|
|**內網電腦**|**各個專責部門**|實際處理請求的終端（如：銷售部、技術支援部） 。|

## 🛠️ 實戰：如何配置埠轉發？

設定埠轉發主要分為兩個核心步驟：**查詢內網資訊** 與 **登入路由器設定** 。

### 第一步：獲取電腦與路由器的 IP 地址

在 Windows 電腦上打開**命令提示字元（CMD）**，輸入 `ipconfig` 並按下 Enter ：

- **IPv4 地址**：你當前電腦的內部 IP（例如：`192.168.1.2`），這是請求最終要送達的地方 。
    
- **預設閘道（Default Gateway）**：這就是你**路由器的內部 IP 地址** 。
    

### 第二步：登入路由器修改設定

1. 打開網頁瀏覽器，在網址列輸入路由器的內部 IP（預設閘道）並登入 。
    
2. 尋找名為 **Port Forwarding（埠轉發）**、**NAT** 或 **Virtual Server（虛擬伺服器）** 的設定頁面 。
    
3. 新增一條轉發規則，填入以下資訊 ：
    

|**欄位名稱**|**輸入範例**|**說明**|
|---|---|---|
|**應用程式名稱**|遠端桌面 (Remote Desktop)|純粹方便你自己識別這條規則的名字 。|
|**外部 / 內部埠號**|`3389`|該服務所使用的邏輯連接埠（例如 Windows 遠端桌面預設為 3389） 。|
|**目標 IP 地址**|`192.168.1.2`|你想要讓外部存取的那台電腦的內網 IP 。|

4. 點擊**儲存（Save）**，設定即刻生效 。
    

## 💡 補充知識：關於「埠號（Port）」

- **定義**：埠號並非物理接口，而是程式與服務用來交換資訊的**邏輯連接識別碼**，用來判定流量的目的（例如是要打開網頁還是傳輸檔案） 。
    
- **範圍**：埠號的範圍是 **0 到 65535** 。
    
- **常用知名埠號（Well-Known Ports，範圍 0 - 1023）** ：
    
    - **Port 80**：HTTP（一般網頁）
        
    - **Port 443**：HTTPS（加密安全網頁）
        
    - **Port 20 & 21**：FTP（檔案傳輸協定）
        
    - **Port 3389**：RDP（Windows 遠端桌面連接）
