### 一、 HTML 核心語法與觀念

HTML（超文本標記語言）是用來建構網頁結構與內容的工具 。它的基本運作方式是透過標籤（Tags）向電腦發出指令 。

#### 1. 元素與標籤結構（Syntax）

一個標準的 HTML 元素通常由**開始標籤（Opening tag）**、內容（Content）**和**結束標籤（Closing tag）組成 。結束標籤的名稱前必須加上斜線 `/` 。

- **語法範例：**
    
    HTML
    
    ```
    <button>Subscribe</button>
    ```
    
    - `<button>`：開始標籤，代表按鈕的起點 。
        
    - `Subscribe`：內容（顯示在網頁上的文字） 。
        
    - `</button>`：結束標籤，代表按鈕的終點 。
        

#### 2. 常見基礎標籤

- `<p>...</p>`：段落元素（Paragraph），用來擺放長條的文字段落 。
    
- `<a>...</a>`：超連結元素（Anchor），用來連結到其他網站 。
    
- `<img>`：圖片元素（Image），屬於空標籤（Void element），不需要結束標籤 。
    
- `<input>`：輸入框/搜尋框元素，同樣不需要結束標籤 。
    
- `<div>...</div>`：區塊元素，常用來將網頁的不同部分分組、排版 。
    

#### 3. HTML 屬性（Attributes）

屬性寫在**開始標籤**內部，用來改變或修改元素的行為 。語法結構為 `屬性名="屬性值"`（中間用等號與雙引號連結） 。

- **超連結屬性範例：**
    
    HTML
    
    ```
    <a href="https://www.youtube.com" target="_blank">Link to YouTube</a>
    ```
    
    - `href`：指定超連結要導向的目標網址 。
        
    - `target="_blank"`：指定點擊連結時要在「新分頁」中開啟 。
        
- **類別屬性（Class）：**
    
    HTML
    
    ```
    <button class="subscribe-button">Subscribe</button>
    ```
    
    - `class`：為 HTML 元素加上「標籤/代號」，方便稍後在 CSS 中精準指定該元素進行樣式修改 。
        

#### 4. 特殊解析規則（Quirks）

- **空格與換行忽略：** 在 HTML 程式碼中輸入多個空格或直接按下 Enter 換行，瀏覽器渲染時都會**自動壓縮成只有一個空格** 。若需要元素與元素間有距離，應使用 CSS 的 Margin 或 Padding 來控制，而不是一直按空白鍵 。
    

### 二、 CSS 核心語法與樣式控制

CSS（層疊樣式表）是用來控制網頁外觀、美化 HTML 元素的工具 。通常會將 CSS 程式碼寫在 `<style>...</style>` 標籤中（非視覺元素，通常放在 `<head>` 內部） 。

#### 1. CSS 語法結構

CSS 由**選擇器（Selector）**、屬性（Property）**與**屬性值（Value）組成 。

CSS

```
.subscribe-button {
  background-color: red;
  color: white;
}
```

- **選擇器 `.subscribe-button`**：以 `.` 開頭代表點選特定的 `class` 名稱 。（若直接寫 `button` 則會套用到網頁上所有的按鈕 ）。
    
- **大括號 `{}`**：內部放置要修改的樣式規則 。
    
- **屬性與值**：中間用冒號 `:` 隔開，每條樣式結尾必須加上分期 `；` 。
    

#### 2. 常用外觀屬性

- `background-color`：背景顏色 。
    
    - 可以直接寫顏色英文（如 `red`、`white`） 。
        
    - 亦可使用更精準的 **RGB 值**，例如 `rgb(200, 0, 0)` 分別代表紅、綠、藍的強度（範圍 0~255） ；`rgb(255,255,255)` 為白色 ，`rgb(0,0,0)` 為黑色 。
        
- `color`：文字顏色（注意不是 text-color） 。
    
- `border`：邊框控制（例如 `border: none;` 可以移除預設邊框） 。也可以細分：
    
    - `border-style: solid;`（實線邊框）
        
    - `border-width: 1px;`（邊框粗細）
        
    - `border-color: blue;`（邊框顏色） 。
        
- `border-radius`：圓角效果 。像素（px）值設定越高，角落就越圓潤 。
    
- `cursor: pointer;`：當滑鼠懸停在元素上時，將游標形狀變成「手型（指標）」，常用於按鈕或連結 。
    

#### 3. 尺寸與間距控制（盒模型 Box Model）

- `height` & `width`：控制元素的寬度與高度（通常使用 `px` 像素作為單位） 。
    
- ==**內邊距（Padding）**：元素內部**內容與邊框之間**的留白距離 。==
    
- ==**外邊距（Margin）**：元素**邊框外部**與其他元素之間的距離 。==
    
- **間距簡寫技巧（Shorthand）：**
    
    - 如果只寫一個值（如 `padding: 10px;`），代表「上、右、下、左」四個方向皆為 10px 。
        
    - 如果寫兩個值（如 `padding: 10px 20px;`），第一個值代表**上下**，第二個值代表**左右** 。
        
    - 如果寫四個值（如 `padding: 10px 20px 15px 5px;`），順序為「上 ➔ 右 ➔ 下 ➔ 左」（順時針方向） 。
        

#### 4. 動態互動效果（偽類 Pseudo-class）

- `:hover`：用來定義當滑鼠游標懸停（移過去）在該元素上方時，所要觸發的特定樣式 。
    
    - **範例：**
        
        CSS
        
        ```
        .shop-link:hover {
          text-decoration: underline; /* 滑鼠移上去時加上底線 */
        }
        ```
