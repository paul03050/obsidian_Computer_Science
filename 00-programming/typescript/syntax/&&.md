在 JavaScript 中，`&&`（邏輯與 / Logical AND）運算子主要是用來檢查多個條件是否同時成立，但它在 JavaScript 裡的實際行為是「短路求值（Short-circuit evaluation）」並回傳最後評估的那個操作數。 [1, 2]

## 核心運作邏輯

根據 [MDN Web Docs 的說明](https://developer.mozilla.org/zh-TW/docs/Web/JavaScript/Guide/Expressions_and_operators)，`&&` 運算子會從左至右評估操作數： [2, 3]

- 遇到第一個「Falsy（假值）」：立刻停止評估，並回傳該假值。
- 如果全部都是「Truthy（真值）」：評估到最後，並回傳最後一個操作數的值。 [2]

> 💡 什麼是 Falsy（假值）？  
> 在 JavaScript 中，只有以下幾種值會被視為假值：`false`、`0`、`""`（空字串）、`null`、`undefined`、`NaN`。其餘所有值（包括空陣列 `[]` 和空物件 `{}`）都是 Truthy（真值）。

## 常見的使用情境

## 1. 條件判斷（最基本用法）

當用於 `if` 語句時，所有條件都必須為真，整個判斷式才會通過。 [4, 5]

```javascript
const age = 20;
const hasLicense = true;

// 兩個條件皆為 true，才會執行內部代碼
if (age >= 18 && hasLicense) {
    console.log("你可以開車！");
}
```

## 2. 短路求值代替 `if`（守衛條款 / Guard Clause）

利用 `&&` 的特性，可以確保左側的變數存在（非空值），才執行右側的方法，避免程式拋出錯誤。

```javascript
// 情境：只有當 user 物件存在時，才讀取其 name 屬性
const user = { name: "Alex" };
const name = user && user.name; 
console.log(name); // 輸出: "Alex" (因為 user 是真值，回傳最後一個值)

const nullUser = null;
const unknownName = nullUser && nullUser.name; 
console.log(unknownName); // 輸出: null (遇到假值立刻回傳，不執行後面，防止報錯)
```

## 3. 在 React 或 UI 渲染中的應用

在前端框架（如 React）中，常常用 `&&` 來決定是否渲染某個元件。

```javascript
// 當 isLoading 為 true 時，渲染載入中的畫面
{ isLoading && <Spinner /> }
```

_⚠️ 注意：如果左側的值是數字 `0`，React 會直接把 `0` 渲染到畫面上，這時建議改用三元運算子或將其轉為布林值 `!!0 && ...`。_

## 4. 邏輯賦值運算子 `&&=`

在現代 JavaScript (ES2021+) 中，你還可以使用邏輯與賦值運算子，只有當左側為真值時，才會將右側的值賦予給它。 [6]

```javascript
let mode = "dark";
// 等同於 mode = mode && "light"
mode &&= "light"; 
console.log(mode); // 輸出: "light"
```
