這份教學內容主要由**彭彭**介紹，說明如何使用 Python 內建的 **venv** 工具來建立與管理專案的「虛擬環境」。以下為關鍵內容的重點總結：

## 💡 為什麼要使用虛擬環境？

- **全域環境（Global Environment）的問題：** 如果直接用 `pip` 安裝套件，所有專案都會共用同一個套件庫 。若 A 專案需要舊版的套件，而 B 專案需要新版，就會發生版本衝突 。
    
- **虛擬環境（Virtual Environment）的好處：** 每個專案（資料夾）都可以擁有**獨立**的套件庫，版本互不干擾、獨立管理 。
    

## 🛠️ 常用指令與操作流程

### 1. 初始化虛擬環境 (Create)

在專案目錄下建立用於管理套件與工具的子資料夾（通常命名為 `.venv`）：

Bash

```
python -m venv .venv
```

> **說明：** 執行後，專案中會生成一個名為 `.venv` 的資料夾，用來存放該專案專屬的套件與執行檔 。

### 2. 啟動虛擬環境 (Activate)

進入專案的獨立環境，啟動後終端機提示字元前會顯示 `(.venv)` 。

- **Windows：**
    
    DOS
    
    ```
    .venv\Scripts\activate
    ```
    
- **Mac / Linux：**
    
    Bash
    
    ```
    source .venv/bin/activate
    ```
    

### 3. 在虛擬環境中管理套件 (Install & Check)

啟動虛擬環境後，使用 `pip` 所安裝或解除安裝的套件，都**只會作用於目前專案** ：

- **安裝套件：** `pip install <套件名稱>`（例如：`pip install numpy`）
    
- **檢視已安裝套件：** `pip list`
    
- **解除安裝套件：** `pip uninstall <套件名稱>`
    

### 4. 離開虛擬環境 (Deactivate)

當需要回到系統的全域環境時，執行以下指令即可 ：

Bash

```
deactivate
```

## 📝 總結對比

|**操作階段**|**指令 / 行為**|**影響範圍**|
|---|---|---|
|**未啟動環境（全域）**|直接執行 `pip install`|套件安裝於電腦全域，所有專案共用 。|
|**已啟動環境（虛擬）**|執行 `activate` 後再 `pip install`|套件安裝於專案內部的 `.venv` 檔案夾，僅供該專案使用 。|
