


物件解構賦值是 ==JavaScript (ES6) 的一種強大語法，允許你從物件中快速提取屬性，並將它們賦值給獨立的變數==。


## 1. 基本用法

在物件解構中，變數名稱必須與物件的「屬性名稱」完全對應，賦值的順序並不重要。


```ts
const user = { name: '小明', age: 18, gender: 'male' };

// 將 name 與 age 提取出來並賦值給同名變數
const { name, age } = user;

console.log(name); // 輸出: 小明
console.log(age);  // 輸出: 18

```

## 2. 重新命名變數
如果你不想使用與物件屬性同名的變數，可以使用冒號 `:` 來重新命名：
```ts
const user = { name: '小明', age: 18 };

// 將 name 屬性解構並賦值給 userName 變數
const { name: userName } = user;

console.log(userName); // 輸出: 小明

```

## 3. 設定預設值
若解構時取不到該屬性（值為 `undefined`），可以替變數設定預設值：
```ts
const user = { name: '小明' };

// 給予 age 預設值 20
const { name, age = 20 } = user;

console.log(age); // 輸出: 20

```

## 4. 陣列其餘運算子（Rest Operator）
你可以使用 `...` 將物件中剩餘未被解構的屬性，打包成一個新的物件：
```ts
const user = { name: '小明', age: 18, gender: 'male', country: 'Taiwan' };

// 將 name 取出，其餘的屬性包進 others 中
const { name, ...others } = user;

console.log(others); // 輸出: { age: 18, gender: 'male', country: 'Taiwan' }

```

## 5. 函式參數解構
這在處理傳入複雜設定值（options）的函式時特別實用：

你可以直接將一個==未命名的物件==解構出來。最常見的使用情境是在==**函式參數**==中，直接解構傳入的匿名物件。
```ts
function printUserInfo({ name, age }) {
  console.log(`姓名: ${name}, 年齡: ${age}`);
}

const user = { name: '小明', age: 18, gender: 'male' };
printUserInfo(user); // 輸出: 姓名: 小明, 年齡: 18

```
